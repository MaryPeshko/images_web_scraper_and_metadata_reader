# Arachnida Projects

Spider is a web crawler that downloads supported image files from a start URL, with optional recursive traversal; see [spider/README.md](spider/README.md).

Scorpion is a CLI tool that inspects image files and prints basic metadata and EXIF information; see [scorpion/README.md](scorpion/README.md).


Projects were implemeted by Maryna Peshko during Sybersecurity Piscine at 42 Berlin in Novermber, 2026.

`Sybersecurity Piscine` is an intesive, one week long course based on peer-to-peer learning, held on-site at 42 Berlin.
